# Интерактивная проверка LearnLoop

Проверено в браузере локального запуска: форма мини-теста отображается, поля курса, вопроса, вариантов и правильного ответа принимают ввод, а интерфейс содержит отдельные действия для CSV- и JSON-экспорта результатов. Тест сохранён, вопрос отображён в рабочей области, а нажатие «Проверить ответ» создало попытку: счётчик пройденных тестов увеличился с 0 до 1.

Оба экспорта проверены end-to-end через безопасный перехват браузерных Blob-объектов. CSV содержит строку заголовка `курс,результат,дата` и запись `SQL основы,1/1`; JSON содержит объект попытки с курсом `SQL основы`, результатом `1/1` и выбранным ответом `Строки`.
